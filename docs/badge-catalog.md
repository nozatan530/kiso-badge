## この一覧の決まり

### バッジの書き方
- 1つのバッジは、**5問で確かめられる1つの技能**にする。「〜できる」「〜がわかる」の形で書く（例：×「一次関数がわかる」→ ○「傾きと1点から一次関数の式を求められる」）
- 学習指導要領の〔知識及び技能〕にあたるものだけをバッジにする。思考力・判断力・表現力等（読解・表現・探究・活用の課題）は、バッジにしにくい力として扱わない
- 学習指導要領に名前が出てこない、教科書で扱う内容には「（教科書で扱う内容）」などと書いた
- 手で書くことが中心のもの（漢字の書き取り、作図、書写、記述式の証明）は外す。作図や証明は「何を作る作図か」「根拠はどれか」を選ぶ形にできる部分だけをバッジにする

### 必須（◎）の付け方
**その技能がないと、あとの学習でつまずくもの**に◎をつける。「大事そうなもの」には付けない。目安は単元のバッジの半分以下（バッジが1つだけの単元は除く）。中身の入っている5単元は、いまあるバッジの必須の設定をそのまま残し、新しく足したバッジには◎を付けていない。

### 問題の形
| 記号 | 形 | いまのアプリ |
|---|---|---|
| 選 | 選択式（choice） | できる |
| 数 | 数値入力（number） | できる |
| 二 | 答え＋理由の二段階（twostep） | できる |
| ＊文 | 短い文字の入力（つづり・読み・語句） | **要追加** |
| ＊並 | 並べ替え（語順・順序） | **要追加** |
| ＊図 | 図・グラフ・地図の読み取り（データから描く） | **要追加**（理科の溶解度曲線・密度表は個別に作ってある） |
| ＊数2 | 2つの数値の入力（連立方程式の解など） | **要追加** |

- `π` や `√` をふくむ答えは、数値入力では答えにくいので「選」にする
- 「選／＊文」のように並べたものは、いまは選択式で作れて、文字入力を足すともっとよくなる、という意味

### 学年の決め方
| 教科 | 学年 |
|---|---|
| 国語・数学 | 学習指導要領が学年ごとに示しているので、**そのまま** |
| 理科 | 学習指導要領の「内容の取扱い」で学年が決まっているので、**そのまま**（第1分野・第2分野とも⑴⑵が中1、⑶⑷が中2、⑸〜⑺が中3） |
| 社会 | **仮置き**。地理・歴史・公民の分野ごとに示され、中1・中2で地理と歴史を並行して学ぶのが原則。学校の年間計画に合わせて動かす |
| 英語 | **仮置き**。文法事項に学年の区別がないので、一般的な教科書の順に置いた。使っている教科書に合わせて動かす |

### IDの付け方
- 単元：`教科-学年-単元名`（例：`math-g2-linear`）。バッジ：`単元ID-b番号`（例：`math-g2-linear-b3`）
- **中身の入っている5つの単元**（`jpn-g1-wordclass`・`soc-g1-world`・`math-g1-integers`・`sci-g1-substance`・`eng-g1-present`）は、いまのバッジ名・必須・番号をそのまま残し、新しいバッジは続きの番号にする（問題と記録がこのIDで結びついているため）
- 中1の単元IDは、いまのアプリのものをそのまま使う
- 中2・中3の単元は、いまのアプリでは大まかな仮の単元しかない（バッジも記録もない）。学習指導要領に合わせて分けたり、名前を直したりした。対応は最後の「いまのアプリの単元IDとの対応」にまとめた

### 見方
各単元の見出しに、単元ID と、対応する学習指導要領の項目（ref）を書いた。バッジは `b番号 ◎ バッジ名〔問題の形〕` の形。
